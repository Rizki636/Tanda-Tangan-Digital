Generator Sertifikat CBT

Baca database spreadsheet CBT apa adanya. Relasi antar sheet (misalnya ID akun di sheet hasil → nama peserta di sheet user) dideteksi otomatis dan bisa diatur manual. Semua diproses di browser Anda.

1Sumber data

Di Google Sheets: File → Unduh → Microsoft Excel (.xlsx). Untuk CSV, satu file = satu sheet (nama file jadi nama sheet).

Ambil langsung dari link hanya jalan bila halaman ini dibuka di luar pratinjau Claude (file HTML mandiri) dan sheet-nya dibagikan “siapa saja yang memiliki link”.

2Pemetaan data

Muat data dulu. Setelah itu sistem menebak sheet hasil, kolom nilai, dan cara mengubah ID akun/ujian menjadi nama.

3Pengaturan sertifikat

Contoh URL verifikasi: https://situs-anda.id/verifikasi?no={no}. Nilai di URL otomatis di-encode.

4Tanda tangan digital (Registri)

Tiap sertifikat dicatat sebagai satu entri di buku register Google Sheet-mu (aksi sign lalu finalize, sama seperti sign.html). QR di area tanda tangan dan QR verifikasi kiri-bawah mengarah ke verify.html?id=…. Hasil akhirnya PDF, karena cek keutuhan di verify.html memang membandingkan hash PDF.
